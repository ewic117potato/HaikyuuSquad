# Haikyuu Legends V17 — Individual portrait preview (PARTIAL, not all characters)

This is a first test release with 12 individually generated high-detail action illustrations (Hinata, Kageyama, Tsukishima, Nishinoya, Tanaka, Ushijima, Bokuto, Kenma, Kuroo, Oikawa, Atsumu and Aone). These are hosted on an external image service, NOT bundled into the ZIP and NOT guaranteed to remain available.

These images are shown within the game for the corresponding 12 character identities. Other school cards still use the existing V16 fallback art. Premium variants for those 12 identities share the generated school-stage artwork and do not yet have separate unique art.

There are 120 distinct school-player identities and hundreds of variants; 108 school-player identities still need individually generated artwork. Staff not yet covered. See public/ai-portraits/ART_PRODUCTION_MANIFEST.json for the remaining roster and prompt specifications.

Open /ai-art-preview.html after hosting to inspect the finished 12. Existing game mechanics, saved data, duels, quests and Supabase setup are unchanged. No live multiplayer or image-host durability validation performed.
