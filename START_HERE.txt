HAIKYUU LEGENDS V8 — ASTRAL COURT
Complete replacement project for GitHub + Render + Supabase.

UPDATE YOUR EXISTING SITE (GITHUB DESKTOP)
1. Extract this ZIP.
2. In GitHub Desktop, select the repository CONNECTED TO YOUR RENDER WEB SERVICE.
3. Repository -> Show in Explorer.
4. Copy the CONTENTS of this extracted folder into that repository root, replacing files when prompted.
   Do NOT place the entire extracted folder inside the repository.
   Do NOT delete the hidden .git folder.
5. GitHub Desktop -> Commit to main -> Push origin.
6. Render should redeploy. Build: npm install | Start: npm start | Root Directory: BLANK
   (only when package.json lives in the repository root).
7. Open your website and refresh. /health should say astral-court-v8.
