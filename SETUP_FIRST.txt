HAIKYUU LEGENDS V6 — UPDATING YOUR EXISTING GAME

1. Unzip V6.
2. GitHub Desktop -> Repository -> Show in Explorer (confirm it is the same repo Render uses).
3. Copy all contents from V6 into that repo. Do NOT copy an enclosing extra folder.
4. Files at repo root must include package.json, server.js, render.yaml, public/, server/, supabase/.
5. GitHub Desktop -> Commit to main -> Push origin.
6. Render -> connected Web Service -> Build npm install, Start npm start, Root Directory blank if package.json is at root.
7. Deploy latest commit. Open your existing Render URL.
8. Pro Shop: Nationals 2,400 / Timeskip 7,500 / Pro 18,000 earned coins per SINGLE CARD pack.
9. Pack odds per pack: Standard 98.9%, Elite 1%, Apex 0.1%. 4-card free school draft is a SEPARATE feature.
10. Quests provide coins and guaranteed milestone players. Progress keeps the previous local save key, with optional Supabase sync.

You do not need to install Node.js on your computer. Render runs the server.
